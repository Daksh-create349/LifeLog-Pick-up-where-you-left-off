Privacy Policy

Effective Date: October 12, 2026 • Policy Version: 2.0 (Local-First Guarantee)
The Core LIFELOG Privacy Guarantee:

LIFELOG is a 100% local-first desktop application and CLI tool. We operate no cloud servers, collect zero remote telemetry, use zero third-party analytics SDKs, and never transmit your computer activity over the Internet. Your data belongs exclusively to you and never leaves your machine.

1. Information That Remains Exclusively Local

When you run LIFELOG, activity metadata is observed locally and stored inside your user-specific directory (~/Library/Application Support/LifeLog) in an SQLite database locked with Unix 0600 permissions.

This strictly local metadata includes:

  • Filesystem Metadata: File paths, sizes in bytes, modification timestamps, and event types (created, modified, deleted) within explicitly configured monitoring directories.
  • Local Git State: Local repository paths, active branch names, HEAD commit hashes and commit messages, and uncommitted working-tree file change lists.
  • Sanitized Command Metadata: When you explicitly execute commands using lifelog terminal record, the command string (with sensitive flags sanitized), working directory, execution timestamp, and exit code are recorded.
  • Active Foreground Application Usage: Foreground application bundle identifiers (e.g., com.apple.Terminal) and elapsed duration timestamps.
  • System Lifecycle Transitions: System sleep, wake, screen lock, and screen unlock timestamps.

2. What We Explicitly NEVER Collect or Inspect

LIFELOG is architected around verifiable technical boundaries that prevent snooping:

  • NO File Contents or Code Diffs: LIFELOG reads file metadata only (os.FileInfo). It never opens, reads, or indexes the text inside your source code, documents, or keys.
  • NO Terminal Output or Shell History: LIFELOG never records stdout, stderr, terminal buffers, or shell history files (.zsh_history, .bash_history).
  • NO Keystroke Recording: LIFELOG contains no keyloggers, event taps, or accessibility keystroke listeners.
  • NO Screenshots or Video: LIFELOG captures zero screenshots, window thumbnails, or screen recordings.
  • NO Window Title Scraping: Window titles are explicitly omitted from capture to prevent collecting private document names or sensitive URLs.
  • NO Web Browsing History or URLs: LIFELOG never reads browser databases, cookies, passwords, URL paths, or query strings.
  • NO Remote Networking or Cloud Sync: The application contains zero remote network connections, analytics trackers, advertising code, or telemetry beacons.

3. Deterministic Secret Sanitization

Before terminal execution metadata is persisted, our heuristic sanitization engine automatically masks sensitive command flags containing tokens, passwords, bearer credentials, and API keys into [REDACTED]. Calls to sensitive credential management utilities (such as security, op, pass, vault, and ssh-add) are omitted.

4. Local Storage and Access Control

All SQLite databases, search indices, and configuration files are written with Unix 0600 permissions, ensuring that only processes running under your operating system user account can read them. Inter-process communication operates strictly over local Unix Domain Sockets (lifelog.sock) protected by ephemeral cryptographic handshake tokens.

5. User Data Portability and Deletion

You maintain complete control over all data recorded by LIFELOG:

  • Full JSON Export: You can export your complete activity history at any time via Settings > Export or lifelog export into a documented, versioned JSON format (lifelog-export-v1).
  • Configurable Retention: You can set automated retention cleanup (7 days, 30 days, 90 days, 365 days, or forever). Expired records and their search index entries are deleted automatically.
  • Granular Deletion: You can purge specific activity sources or date ranges via Settings > Data Management.
  • Complete Removal: Deleting the ~/Library/Application Support/LifeLog directory permanently eliminates all traces of stored data from your computer.

6. Open Source Verification

LIFELOG is free and open-source software released under the MIT License. The entire Go backend, Swift observer helper, and Electron desktop shell are publicly available on GitHub for independent security and privacy auditing.
