LIFELOG Documentation

LIFELOG is a local-first computer memory engine for macOS designed to help software engineers pick up exactly where they left off. It runs as both a lightweight Go CLI and an Electron desktop application.

Quickstart Guide

Get started in three terminal commands:

1. Initialize LIFELOG

Creates your local data directory in ~/Library/Application Support/LifeLog with restricted 0700 permissions and sets up SQLite schema v9:

lifelog init

2. Start Monitoring a Directory

Recursively monitors directory modifications without inspecting file contents:

lifelog watch /path/to/my-project

3. Generate a Resumption Report

When returning to work after hours or days away, generate an instant context synthesis:

lifelog resume

Installation Guide

macOS Desktop Application (Apple Silicon M1/M2/M3/M4)

Download the standalone .dmg installer:

Download LifeLog-0.2.0-arm64.dmg (117 MB)

Drag LifeLog.app into your /Applications folder. On first launch, if macOS Gatekeeper prompts for an unidentified developer, right-click the app and choose Open, or run:

xattr -cr /Applications/LifeLog.app

Homebrew CLI Installation

brew install lifelog

Source Build (Go 1.22+)

git clone https://github.com/Daksh-create349/LifeLog-Pick-up-where-you-left-off.git
cd LifeLog
CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o lifelog main.go
./lifelog doctor

Desktop Application Architecture

The desktop app uses Electron with React, Tailwind CSS, and Lucide icons. It communicates with the Go daemon through a Unix Domain Socket (UDS) located at ~/Library/Application Support/LifeLog/lifelog.sock.

Every socket connection requires an ephemeral token handshake. The Electron main process spawns the Go daemon with the token passed securely in an environment variable, preventing any unauthorized local processes from connecting.

Native macOS Application Tracking

Tracks the active foreground application name and bundle identifier using macOS NSWorkspace.shared.frontmostApplication and NSWorkspaceDidActivateApplicationNotification.

  • No Accessibility permissions required: Pure public macOS APIs.
  • Zero window title capture: Window titles are explicitly excluded for privacy.
  • Zero keystrokes: No global event taps, keyloggers, or text inspection.
  • Session duration clamping: Automatically closes orphan sessions upon sleep or reboot.

System Activity Tracking

Tracks computer lifecycle transitions via native macOS notification hooks:

  • system_sleep: Emitted when the Mac enters sleep mode. Active sessions are automatically finalized.
  • system_wake: Emitted when the Mac wakes up. Fresh foreground tracking resumes.
  • system_lock: Emitted via DistributedNotificationCenter when the screen locks.
  • system_unlock: Emitted when the user logs back in.

Data Management & Retention

LIFELOG provides automated retention cleanup via Settings > Data Management. Users can configure cleanup presets:

  • 7 Days: Ideal for high-turnover staging machines.
  • 30 Days: Recommended for daily development work.
  • 90 Days / 365 Days: Extended retention for quarterly reviews.
  • Keep Forever: Never expires records.

Cleanup runs in bounded database transactions and deletes associated entries from the FTS5 search index via database triggers, guaranteeing no dangling records.

Security Hardening Model

  • Restricted File Permissions: Data directory created with 0700; databases and exports created with 0600.
  • Timing Attack Defense: Auth tokens are verified using crypto/subtle.ConstantTimeCompare.
  • Sandboxed Electron Shell: Context isolation enabled, Node.js integration disabled, external navigation prevented.
  • No Remote Sockets: The daemon only binds to local Unix Domain Sockets. No network attack surface.
